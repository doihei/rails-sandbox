## i18n（国際化）規約

このプロジェクトは `rails-i18n` を使用し、`ja` をデフォルトロケール、`en` をフォールバックとして運用する。

### ロケールファイルの構成

```
config/locales/
  ja.yml          # 日本語（正典）
  en.yml          # 英語（フォールバック）
  devise.ja.yml   # Devise システムメッセージ（日本語）
  devise.en.yml   # Devise システムメッセージ（英語フォールバック）
```

- `ja.yml` が主体。新しいキーは必ず `ja.yml` と `en.yml` の両方に追加する。
- `ja` に翻訳が見つからない場合は自動的に `en` へフォールバックする（`config.i18n.fallbacks = true`）。

### キー構成の方針

```yaml
ja:
  app_name: "Rails Sandbox"       # アプリ共通

  articles:                        # コントローラ名
    index:                         # アクション名
      title: "記事一覧"
    form:                          # パーシャル名
      title_label: "タイトル"

  flash:
    article:
      created: "記事を作成しました"

  nav:
    logout: "ログアウト"

  article_status:                  # モデルのステータス値
    draft: "下書き"
```

### View での使い方

**Lazy lookup（推奨）**: アクション・パーシャルに対応するキーを自動解決する。

```erb
<%# articles/index.html.erb → ja.articles.index.title %>
<h1><%= t('.title') %></h1>

<%# articles/_form.html.erb → ja.articles.form.title_label %>
<%= form.label :title, t('.title_label') %>
```

**絶対パス**: レイアウトや共通部品など、コントローラスコープが合わない場合に使う。

```erb
<%# layouts/application.html.erb %>
<%= t('app_name') %>
<%= t('nav.logout') %>
```

### Controller での使い方

```ruby
redirect_to @article, notice: t("flash.article.created")
```

### 動的キー（ステータスバッジなど）

```erb
<%= t("article_status.#{article.status.value}") %>
```

### 新しいキーを追加するときの手順

1. `ja.yml` に日本語テキストを追加する
2. `en.yml` に同じキーで英語テキストを追加する
3. Devise 関連のメッセージは `devise.ja.yml` / `devise.en.yml` に追加する
4. View / Controller で `t()` を使って参照する
