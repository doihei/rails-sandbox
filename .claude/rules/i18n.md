## i18n（国際化）規約

このプロジェクトは `rails-i18n` を使用し、`ja` をデフォルトロケール、`en` をフォールバックとして運用する。

### ロケールファイルの構成

```
config/locales/
  ja.yml              # 共通キー（errors）
  en.yml              # 同上・英語
  articles/
    ja.yml            # articles.* キー（日本語）
    en.yml            # articles.* キー（英語）
  comments/
    ja.yml            # comments.* キー（日本語）
    en.yml            # comments.* キー（英語）
  likes/
    ja.yml            # likes.* キー（日本語）
    en.yml            # likes.* キー（英語）
```

- リソース単位でサブディレクトリに分割する。新しいリソースを追加するときは `config/locales/<resource>/ja.yml` を作成する。
- Rails はデフォルトでは1階層しか読まないため、`config/application.rb` に以下の設定が必要（設定済み）：
  ```ruby
  config.i18n.load_path += Dir[Rails.root.join("config", "locales", "**", "*.{rb,yml}")]
  ```
- `ja` に翻訳が見つからない場合は自動的に `en` へフォールバックする（`config.i18n.fallbacks = true`）。

### キー構成の方針

```yaml
ja:
  errors:                          # GraphQL Mutation / Service 共通エラー
    login_required: "ログインが必要です"
    unauthorized: "この操作を行う権限がありません"
    stale_object: "他の人が先に更新しました..."

  articles:                        # リソース固有エラー（articles/ja.yml に定義）
    errors:
      not_found: "記事が見つかりません"
    publish:
      errors:
        unauthorized: "..."

  comments:                        # リソース固有エラー（comments/ja.yml に定義）
    errors:
      body_blank: "本文を入力してください"
      body_too_long: "本文は%{max}文字以内で入力してください"
      not_found: "コメントが見つかりません"
      unauthorized: "このコメントを操作する権限がありません"
```

### GraphQL Mutation / Service での使い方

```ruby
# Mutation 内（認証チェックは AuthenticatedMutation の ready? が自動で行う）

# Mutation 内（レコード存在チェック）
return { article: nil, errors: [I18n.t("articles.errors.not_found")] } unless article

# Service 内（楽観的ロック競合）
Result.failure(I18n.t("errors.stale_object"))

# Service 内（認可エラー）
raise OwnershipError, I18n.t("errors.unauthorized")
```

### ActiveRecord バリデーションエラー

バリデーションの `message:` オプションにハードコードせず、`activerecord.errors.models` 配下に定義する：

```yaml
ja:
  activerecord:
    errors:
      models:
        some_model:
          attributes:
            some_attribute:
              taken: "はすでに登録されています"
```

モデル側では `message:` を省略する：

```ruby
validates :some_attribute, uniqueness: { scope: :other_attribute }
```

Rails は `:taken` キーで `activerecord.errors.models.<model>.attributes.<attr>.<key>` → `activerecord.errors.models.<model>.<key>` → `activerecord.errors.messages.<key>` の順にルックアップする。

### 新しいキーを追加するときの手順

1. リソース名に対応するサブディレクトリのファイル（例: `config/locales/articles/ja.yml`）に日本語テキストを追加する
2. 同じファイルの `en.yml` に英語テキストを追加する
3. `errors` / `activerecord` などアプリ共通のキーはルートの `ja.yml` / `en.yml` に追加する
4. GraphQL Mutation / Service で `I18n.t()` を使って参照する
